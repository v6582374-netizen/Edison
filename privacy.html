Privacy Policy

隐私说明

版本：2026-10-23 · 适用于所有者个人使用的 Edison 自托管实例及其 PersonalFeed Google 授权应用。

读取哪些数据，为什么读取

在你同意 Google 的 YouTube 只读授权后，Edison 读取订阅关系、频道标识及信息、视频标识及元数据，用于发现订阅更新、识别视频来源和组织阅读资料。Edison 不请求通过这项授权上传、修改或删除 YouTube 内容。

当你许可视频处理时，实例会获取其实际有权访问的字幕或其他受支持的源内容，保存来源、译文、生成文稿、处理状态、文稿版本和阅读记录。视频内容访问与 Google 官方订阅授权是两个独立连接。

存储与凭据

持久资料保存在实例所有者控制的服务器上。Google 授权凭据、YouTube 内容会话及模型服务凭据与文稿资产分别管理，不随文稿导出。实例管理员负责服务器访问、备份及部署配置。

程序保留处理、连接和恢复所需的运行记录。运行记录不应包含授权令牌、客户端密钥、密码或内容会话凭据。项目不运营另一份用户资料库或同步副本。

数据会传给谁

读取订阅和内容时，实例与 Google、YouTube 进行认证及内容请求。为完成你选择的翻译和成稿，实例会把所需的源内容及相关视频信息发送给实例所有者配置的模型服务。Google 客户端密钥、后台授权令牌及内容会话凭据不作为模型输入。

实例所有者应根据自己选择的模型提供商及其数据处理条款决定是否启用处理。Edison 项目本身不出售 Google 用户数据，不将其用于广告画像或训练通用人工智能模型，也不把私人资料公开给其他 Edison 实例。

Edison 对从 Google API 接收的信息的使用和传输遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

保留、断开与删除

知识资产及阅读记录保留到实例所有者明确删除，不因视频变旧、退出 Edison 或断开 Google 授权自动删除。断开 YouTube 会停止继续使用两条连接并清除实例中的对应凭据，保留已有知识资产；本地清除与 Google 平台是否成功撤销分别报告。

你还可以在 Google 账号的第三方连接页面撤销应用权限。需要彻底删除资料时，由实例管理员删除相关资产、状态资料和持有的备份；撤销 Google 权限本身不会删除既有文稿。

这些公开说明页面

本页面不使用访问分析脚本、广告或第三方嵌入，不调用 Edison 私人资料库。页面托管服务仍会按其自身规则处理提供网站所需的请求信息；若由 GitHub Pages 托管，适用 GitHub 隐私声明。

联系与更新

实例的数据管理问题由实例所有者处理。软件问题可以通过 项目 Issues反馈；公开反馈中不要提交任何凭据或私人资料。数据处理方式变更时，本说明会同步更新日期和内容。
