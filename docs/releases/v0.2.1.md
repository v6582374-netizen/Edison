# Edison v0.2.1 — 首个桌面发行版

Edison 将对话工作区、YouTube 阅读资料库、Minimalism 物品记忆和课程周览整合到同一个 macOS 应用。

## 本版功能

- **YouTube 阅读**：订阅更新、保留完整译文的中文阅读稿、时间流／文档库／频道索引、稿件版本与来源追溯。
- **处理进度**：逐条或批量取消与恢复、Shorts 排除、共享限流冷却、失败重试、实时处理阶段和控制台。视频条目显示 YouTube 发布时间与视频时长，文稿预计阅读时长独立标注。
- **Minimalism**：物品、集合、照片与记忆、归档和回收站、备份恢复、AI 封面预览与采用。可复制迁入原 Minimalism 资料，保留原件。
- **Curriculum**：课程周览、学期与节次信息、原生上下课通知。
- **统一工作区**：模型设置、中英文切换、明暗主题和桌面窗口体验。

## 下载与安装

支持 **Apple Silicon（M 系列芯片）、macOS 14 Sonoma 或更高版本**。

1. 下载 `Edison_0.2.1_aarch64.dmg`，打开后将 Edison 拖入 Applications；也可解压 `Edison_0.2.1_aarch64.app.zip`。
2. 本版采用 **ad-hoc 签名，未经 Apple Developer ID 签名与公证**。macOS 可能阻止首次启动；确认来源后，在“系统设置 → 隐私与安全性”中允许打开。
3. 在应用设置中配置自己的模型服务。YouTube 订阅连接需要个人 Google OAuth 配置及本机 Automic Vault。

发布页提供 `SHA256SUMS.txt`，可用 `shasum -a 256 -c SHA256SUMS.txt` 核对下载文件。安装包不附带模型密钥或个人资料库，不清空已有视频和物品资料。

## 已知范围

- 本次仅提供 macOS Apple Silicon 安装包；未提供 Intel、Windows 或 Linux 安装包。
- 更新通过手动下载安装完成，本版没有自动更新通道。
- 未取得的发布日期或视频时长明确显示未知；视频时长在新视频正常获取元数据时保存，不批量补齐历史条目。
- 图像生成和语言模型需要自行配置的外部服务；订阅获取仍受 YouTube 平台访问限制。

v0.2.1 发布时源码包含固定版本的 Vegapunk 参考子模块；当前主分支已移除该子模块，无需递归克隆。已迁入代码的来源与许可证仍保留。GitHub 桌面发行不会自动触发 PyPI 发布。
