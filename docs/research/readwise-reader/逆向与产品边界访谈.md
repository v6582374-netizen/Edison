## 已确认的方向

- 产品拥有自己的数据与服务，不以持续连接 Readwise 服务为产品前提；旧 Reader 数据导入可后续考虑，第一期明确不迁移。
- 从 Edison 左侧导航进入，在主区域展开完整阅读模块。
- 先还原个人核心阅读闭环，其余能力分期补齐。
- 分析对象限定 Readwise Reader，不包含 Readwise 的独立回顾产品。
- 本次先交付逆向证据、领域模型、分期开发方案；之后另进入实现。
- 最新范围仅 EPUB，PDF 已移出第一期；新导入 → 收件箱/稍后/归档 → 阅读与续读 → 高亮、笔记 → 搜索与导出为完整闭环。
- 资料与批注保存于 Edison 自有服务器，第一期只验收当前电脑使用。
- 第一期开独立入口，只管理主动导入的 EPUB，不承接课堂与 YouTube 资料，不迁移已有 Readwise 数据。
- 忠实研究阅读逻辑与关键交互，外观适配 Edison。

## 已核实的外部事实

### REA 官方范式

官方同时提供 MCP 和 CLI，二者使用相同应用分析工作流与 Evidence 契约。静态 JavaScript 分析不需要先注册 MCP，也不需要 Hopper/Ghidra。应先识别结构，再追踪具体能力，并区分静态推断与运行观察。

- [中文 README](https://github.com/morluto/rea/blob/main/README_zh.md)
- [CLI 工作流](https://github.com/morluto/rea/blob/main/docs/cli.md)
- [JavaScript 功能追踪](https://github.com/morluto/rea/blob/main/docs/javascript-application-workflows.md)

网站观察要求 Chrome 系浏览器与 CDP；Zen 基于 Firefox。因此已有 Zen 标签页可用于界面观察，不能直接假定是 REA 支持的捕获目标。此兼容性判断来自官方支持范围，尚未本机测试连接。

- [REA 浏览器观察](https://github.com/morluto/rea/blob/main/docs/browser-observation.md)
- [Zen 架构说明](https://docs.zen-browser.app/security)

REA setup 会注册 MCP、安装匹配工作流指引并备份配置；支持 dry-run，正式配置后要求重启相关代理。Node 版本有明确约束，实际使用时需核对已发布包版本，不能假定 main 文档中的全部能力均已发布。

- [REA 安装说明](https://github.com/morluto/rea/blob/main/docs/installation.md)

### Readwise 公开资源的边界

官方组织公开仓库调查尚未发现完整 Reader 产品本体仓库。桌面发布仓库是安装包分发入口；发布包内的源映射随后提供了可分析的客户端源码内容，仍不等于完整仓库。官方 CLI 是连接托管服务的客户端，不能替代独立产品的后端。旧公开 readwise-mcp 仓库已标 Deprecated。

- [官方组织](https://github.com/readwiseio)
- [桌面发布仓库](https://github.com/readwiseio/reader-desktop-releases)
- [官方 CLI](https://github.com/readwiseio/readwise-cli)
- [旧 MCP 仓库](https://github.com/readwiseio/readwise-mcp)
- [当前托管 MCP](https://readwise.io/mcp)

官方 Reader REST API 公开保存、文档读取、部分正文与原文件获取、元数据和分类更新、高亮与笔记等能力。文档返回阅读进度，但未列出进度更新接口；RSS 管理、朗读、Ghostreader、完整客户端同步协议不在已核实的 REST 文档能力内。这是公开文档边界，不能据此断言后台不存在相关接口。

- [Reader REST API](https://readwise.io/reader_api)

桌面版更新清单的 Tauri 签名是最初线索。随后已下载并核验官方 0.1.3293 包，确认原生 Tauri 标记与 localhost 资源服务，取得 JavaScript/source map；没有采用 Electron/ASAR 假设。

- [官方下载入口](https://readwise.io/read/download)
- [桌面版 Releases](https://github.com/readwiseio/reader-desktop-releases/releases)
