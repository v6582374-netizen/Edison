# Reader 阶段 2：可靠续读验收

2026-10-14。本阶段在 Edison 本地生产构建与隔离真实 FastAPI 上验收；没有部署、提交或推送。承接[阶段 1](./stage1-validation.md)，下一阶段为高亮、笔记与 Notebook。

## 本阶段交付

停读位置、最远到达位置和每本书的字号/目录展开状态保存到同一服务器。刷新或重新打开时，先恢复排版偏好，再按精确 CFI 恢复原位置。位置绑定不可变的内容版本，恢复不会产生一次新的阅读记录。

这三个概念必须分开：**停读位置**回答“下次从哪里继续”；**最远到达位置**回答“曾经导航到哪里”；**读完或理解**不由本阶段判定。主动跳到末章会推进最远到达，回读不会倒退。字号、窗口宽度和侧栏变化只改变排版，不推进记录。

进度展示按章节等权加章节内 UTF-16 文字偏移估算，并非读完字数或真实页数；精确定位从不依赖百分比。图片页保留图片/SVG 元素锚点，纯无文字章节使用章节锚点，这不扩大阶段 1 对独立图片/SVG spine 的支持范围。

## 保存与恢复契约

- 阅读记录与书库归类各有独立修订号。一次书库归类不会制造阅读冲突。
- 同一阅读页顺序写入；连翻后回读仍保留过程中最远的位置。只有服务器确认后才显示“已保存到服务器”。
- 请求失败保留此页草稿；重试复用原操作身份。请求已提交但响应丢失时，重试不会重复增加修订号。其他页面已经推进服务器版本时，旧写入返回冲突。
- 冲突不自动覆盖；用户可明确“采用服务器记录”。保存失败时，站内离开会等待或阻止离开，浏览器离开则注册 beforeunload 提醒。
- 文字锚点保存章节、CFI、原文摘录、正文前缀偏移及正文长度；保存和恢复均核对。摘录最多 48 个 UTF-16 单位，不截断尾部代理对。跨标签的 DOM Range 先规范化端点。
- 原文不符时保留服务器记录并显示恢复失败。用户可安全离开，也可明确从头重新记录；重新记录停读起点不抹去最远到达。
- 服务端校验认证、内容版本、字段形状和章节序号边界；正文/CFI 的 DOM 对应由阅读端核验。服务端并不声称已经独立重排 EPUB 并验证原文。

## 验证

最终结果：Reader 三浏览器 **36/36**，Reader Python **25/25**（新增阅读记录 12 项、书库 13 项），Curriculum E2E **11/11**，前端认证 **2/2**，原有 Reader/网页登录 **6/6**，认证与跨源边界 **4/4**；生产构建通过。测试从真实文件输入与 Reader 导航进入，使用临时服务器数据库及生产 GUI；不是把保存接口全部 mock 成成功。

| 验证范围 | 覆盖 |
|---|---|
| Reader Python | 服务器重读、停读/最远分离、偏好、归类独立、快速前进回退、重复操作、并发首写、版本/数据校验、认证 |
| 三浏览器 Reader E2E | Chromium / Firefox / WebKit；原有书库流程、真实中文书、重排/刷新/重开、图片页、双页面冲突、断网重试、丢响应重试、原文失配、真实 401、EPUB2、竖排、RTL、内嵌字体 |
| 宿主回归 | Curriculum 档案 11 场景、前端认证、原有 Reader/网页登录、认证与跨源边界 |
| 构建 | TypeScript 与 Vite 生产构建，保留既有大 chunk 提示 |

浏览器弹窗测试使用页面发起的真实 reload，并关闭 Playwright Firefox 默认的 beforeunload 禁用设置。浏览器是否在崩溃、强制关闭或系统回收时提示，不在保证范围内。特殊排版验收核对完整摘录身份和原起点可见性；放大字体后摘录可跨页，不能要求整个摘录仍在一页内。

本轮 E2E 先复现并修复：退出时分页器回调访问已销毁文档、快速导航被内核页锁忽略、图片页缺少文字锚点、恢复完成前误显示已保存。生命周期修复包括 React 卸载前停止内核，以及固定 Foliate 源码中选择事件的空 selection 检查。当前共五处精确匹配的分页器保护，开发与生产共用；上游升级不匹配时阻断构建，没有手改 node_modules。

## 重跑

从 Edison 仓库根目录执行：

```sh
.venv/bin/pytest tests/test_reader_reading.py tests/test_reader_library.py -q
.venv/bin/pytest tests/test_web_auth.py tests/test_reader.py -q
cd surfaces/gui
npm run build
npx playwright test -c playwright.reader.config.ts
npx vitest run src/api.auth.test.ts
npx playwright test -c playwright.config.ts e2e/curriculum-archive.spec.ts
```

设置 `EDISON_READER_TEST_EPUB` 可加验本机真实书；设置 `EDISON_READER_LAYOUT_DIR` 可加验阶段 0 的 `vertical.epub`、`rtl.epub`、`font.epub`。二者不设置时，相应测试明确跳过，不能把默认运行称为完整 36 场景验收。合成 EPUB2/3 fixture 随仓库提供。

## 限制与下一阶段

没有离线持久队列；服务器确认前若强制关页或崩溃，待保存草稿仍可能丢失。没有自动按摘录寻找替代锚点、内容版本迁移或百分比降级。尚未验收跨设备、超大书性能、手机端或线上部署。实际 Zen 应用未在本轮重新操作，Firefox 自动化不能冒称 Zen 本体验收。

下一阶段是批注闭环：文字高亮、整本/高亮笔记和 Notebook 回跳。它需要稳定范围身份、重排后绘制和原文失配状态；不能把本阶段的单个停读起点当成完整高亮范围。

本轮所有测试均使用 headless 浏览器，未打开可见窗口或预览；测试服务与浏览器由框架关闭，端口清理另经核对。原有其他模块未提交的修改保持原状。

后续阶段 3 已于 2026-10-15 完成本地验收，见[批注闭环验收](./stage3-validation.md)。本页保留阶段 2 当时的范围与结论。
