# Minimalism 融入 Edison

> 当前物品模块的显示名称为 **items**（2026-10-09 更名）。本文中的 Minimalism 为集成时的历史名称和原资料来源；存储与备份格式不变。

设计访谈的九项决策及整体方案已获确认，现已完成实现。交付行为和验证范围见 [交付说明](minimalism-delivery.md)。

## 已确认

- **模块名称**：Edison 侧边栏中的用户可见名称为 **Minimalism**，保留名称不意味着保留原应用的独立视觉体系。
- **产品归属**：Edison 成为唯一日常入口，Minimalism 保留为迁移来源，不维持两套产品同步演进。见 [ADR 0006](../adr/0006-edison-as-sole-entry-for-minimalism.md)。
- **视觉归属**：以 Edison 当前桌面客户端的整体风格为准；物品画廊及交互适配 Edison 的视觉体系，不保留另一套独立应用外观。
- **功能范围**：迁入完整的已实现物品记忆系统，包括物品、集合、档案照片、记忆文本、归档和 AI 封面。Minimalism 文档规划中的 Skills 管理不在本次范围内。
- **资料迁移**：一次性复制现有完整资料库与图片，迁入后由 Edison 独立管理。Minimalism 原资料保留，双方不再同步。见 [ADR 0007](../adr/0007-copy-minimalism-data-into-edison.md)。
- **迁入时机**：首次进入 Minimalism 模块时自动迁入并显示进度，完成后直接呈现原有物品；仅在目标资料库为空且尚未迁移时执行，失败可重试。
- **生图设置**：供应商、图像模型与凭据纳入 Edison 统一设置入口，使用独立于聊天模型的图像生成配置；封面提示词归物品模块设置。
- **旧配置处理**：仅迁入原封面提示词，不迁入 Minimalism 的旧端点、模型或 API Key。生图服务在 Edison 中重新配置；已迁入的图片与封面不受影响。
- **呈现方式**：作为 Edison 侧边栏入口对应的主内容区模块，沿用宿主侧边栏折叠能力。
- **验收边界**：保留全部现有用户能力和数据语义，具体布局、手势与控件按 Edison 规范调整；不要求逐项复刻原 SwiftUI 交互。例如价格仍可查看，但不强制沿用双击翻卡。

## 实施方案

沿用 Edison 当前桌面宿主，将物品界面迁为主内容区中的 React 模块；资料管理通过 Edison 现有本地服务体系承接，物品资料保持独立边界。此次不引入第二个应用宿主或通用插件框架。

先在原 Minimalism 中核对实际可用的端到端流程，形成迁移验收清单，再实现资料承接、模块界面及生图设置。功能完整性以原应用的实际能力为准，包括基础物品管理之外的集合管理、元数据、档案照片、记忆编辑、归档恢复、备份恢复及封面生成确认等流程。

首次进入模块时，存在旧资料且目标为空则执行一次性迁入；没有旧资料时展示可用的空画廊。生图服务未配置时，浏览、编辑与资料管理正常可用，主动发起生图时引导至统一设置。

具体工程选择在上述产品边界内完成。

## 实施约束

- 一次性迁移需要完整性校验与完成标记，失败可重试，成功后不重复导入；不得静默覆盖 Edison 已有物品资料。
- 仅迁入封面提示词，不读取或迁移旧生图凭据，不覆盖 Edison 已有生图服务配置；凭据不得进入物品资料备份。
- 实施时以原应用实际可用流程核对功能清单；文档中的规划不自动计入已有功能。

## 验收重点

- 首次迁入后，物品、集合关系、照片、记忆、元数据、归档状态及已有封面完整可用；原资料未被修改。
- 重启或再次进入模块不会重复导入；迁移中断后可恢复或重试，不呈现已完成迁移的假象。
- 物品系统完整流程在 Edison 内可用，导航、视觉和交互遵循 Edison；其他模块不因本次融合退化。
- 封面提示词正确迁入，旧服务配置和凭据不迁入；配置新服务后可完成生成、预览、采用或取消的完整流程。
- 使用真实桌面交互及隔离资料验证关键端到端路径，避免测试修改原 Minimalism 资料。

## 已核实的设计背景

Edison 当前桌面入口是 `surfaces/gui`（React/Tauri），`desktop` 目录是保留的旧客户端。Minimalism 的现有界面是 SwiftUI，当前实现围绕物品记忆系统；Skills 管理仅见于其设计文档。

Minimalism 使用独立的本地 SQLite 资料库和图片目录；应用偏好及生图凭据分别存储。现有资料迁移、界面迁移与设置整合分别遵循已确认的归属边界。原源码隔离检查、实际资料临时迁移和 Edison 端到端验证的范围记载于交付说明。
