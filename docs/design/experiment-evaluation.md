# Fixed samples and comparison evidence

This module supports the isolated comparison specified in [Edison 长内容处理的隔离对照与替换决策验证](https://github.com/vincentshuo/Edison/issues/68) and [建立可复现的样本与评价流程](https://github.com/vincentshuo/Edison/issues/75). It does not start production services, acquire new sources, create a model client or certify translation quality.

## Private fixed samples

`youtube_strataread.workbench.experiment_evaluation` exposes `Sample`, `freeze_manifest(path, samples)` and `load_manifest(path)`. Create a manifest outside Git from copied private caption snapshots. Each sample declares an opaque sample id, video identity, language, source kind, development/held-out split, independently measured duration and its evidence, and verified coverage categories. The manifest stores absolute private source paths, raw SHA-256, bytes, characters and original SRT cue count, not subtitle text. Its own identity hash fixes both metadata and source identity. Loading verifies that hash and every source's bytes.

All outputs are created exclusively with mode `0600`; existing files are never overwritten. Default and configured production stores and symlink output paths are refused. Snapshot files are read only. Copy live sources out of production before building the manifest, retain the copied raw files unchanged, and keep the manifest private: video identities and paths may themselves be sensitive. Metadata such as duration is a declaration backed by the supplied evidence, not something the code independently verifies against YouTube. Never put credentials or authenticated URLs in sample/model metadata.

`source_kind` is `speech-captions`, `synthetic`, `chat` or `absent`. Only real speech-caption samples contribute to `sample_gaps(manifest)`. Approximately two hours means a known duration between 6,300 and 8,100 seconds; approximately four hours means 12,600–16,200 seconds. End timestamps, unknown duration and category labels cannot substitute for those measured durations. Additional required categories are `short-english`, `chinese-or-mixed`, `multi-speaker` and `number-dense`; assign these only when the copied source has been checked. The matrix also requires held-out speech material. Synthetic samples exercise contracts but never fill a real-material gap.

A source hash or video identity cannot appear in both development and held-out sets. A sample declared `used_for_tuning=True` cannot be labeled held-out. This prevents accidental reuse represented in the manifest; it cannot detect undisclosed tuning. If held-out output informs a prompt or implementation change, relabel it development and freeze a new independent held-out set. Do not keep tuning against it and call later results independent acceptance.

## Bounded run order

`build_plan(path, manifest, model_identity=..., settings_sha256=..., representative_ids=(...), repeats=2, segmentation="fixed-common-source-units")` fixes A/B/C runs for every sample. Groups rotate `A,B,C`, `B,C,A`, `C,A,B`; selected representative samples repeat one to three times, with order and repetition number recorded. `load_plan(path, manifest)` verifies the fixed plan identity and source-set binding before execution. Nothing in these functions launches a benchmark or automatically expands the sample set.

Use the same credential-free model/proxy identity, common settings and source units for the main mechanism comparison. Record each plan row alongside the produced run id in the private evidence index. Choose representatives before viewing results. If comparing segmentation, freeze another plan with a distinct segmentation identifier, keeping other factors fixed; do not mix its improvement with a translation-mechanism change. A hash records the chosen settings, not proof that a proxy honors them; real capability evidence comes from the provider contract probes.

## Source-aligned evaluation

`evaluate_run(run_json_path, checks, source_kind="synthetic")` reads the actual independent translation and manuscript artifacts produced through the existing preparation runner. `ExpectedCheck(id, dimension, source_cues, alternatives=(), forbidden=())` ties a known synthetic expectation to an inclusive range of **original raw SRT cue ordinals**, before cleanup/merging. Supported dimensions are omission, addition, number, unit, negation, qualification, terminology, entity, order and readability. A check needs accepted literal alternatives, forbidden phrases, or both. Number alternatives can explicitly accept both `25` and `二十五`. Order anchors are compared according to their source cue ranges. Only annotated synthetic dimensions receive pass/fail; unannotated dimensions remain unknown.

These checks are deliberately narrow: a number occurrence cannot establish its unit, owner or negation. Separate unit, entity and negation annotations exercise those known synthetic errors. A synonym can fail a literal check while preserving meaning; an unannotated invented fact may pass it. For real sources the same checks remain diagnostic `annotated_dimensions`, while quality `dimensions` stay unknown. They are never a universal omission/addition detector.

`evaluate_with_judge(run_json_path, judge_callback, model_identity=..., method_id=..., limitations=...)` is the optional external automatic evaluation boundary. The callback receives original timed source cues, complete translation and manuscript privately. It returns decisions by dimension, each with `status`, `source_cues`, `source_quote`, `artifact` (`translation` or `manuscript`) and `output_quote`. Non-unknown decisions must quote actual retained source and output within the declared range; invalid evidence is rejected. Missing decisions stay unknown. Record the judge's exact model identity, versioned method/prompt identity and limitations. The callback may implement an approved configured provider; this module never selects credentials or opens a network connection itself.

A quote-backed automatic decision is still a fallible judgement, not independent proof of correctness. The returned result always sets `semantic_fidelity_certified: false`. Save the complete evaluation result only in private evidence; source/output quotes must not appear in public aggregate reports. No owner semantic-adjudication queue is introduced. A failed generation is not evaluated as a good translation merely because an earlier workspace version exists.

## Run summaries

`summarize_runs(path, record_paths, evaluations=[...])` consumes the runner's `run.json` protocol and optional evaluation results. It writes per-run state/reason, request attempts, total elapsed time, stage elapsed times when present, recovery metadata when present, separately estimated and provider-reported input/output/cache usage, usage coverage, unknown cost, and known/unknown quality dimensions. Missing fields remain `null`; historical mixed `budget_tokens` are never promoted to measured consumption. Partial reported totals are accompanied by coverage rather than implying all calls were measured. Duplicate run ids and evaluation source mismatches are refused.

Per-variant aggregates include raw sample/run counts, ready counts, attempts, observed latency P50/P95 and available reported usage. Quantiles use linear interpolation and are descriptive at small n, never population guarantees. Runs carry a comparison identity derived from source, model, common settings and segmentation. The runner may supply `comparison_settings` separately from variant-specific prompt settings; otherwise all settings are included conservatively. Pair only identical comparison identities. Aggregating unmatched sources or changed models cannot show a mechanism gain. No missing evaluation is counted correct, and unknown cost does not become zero.

## Evidence available at implementation

Five private English snapshots have been fixed separately from this repository's source: two short samples, two longer samples including one measured at approximately two hours, and a subsequently acquired public speech-caption source measured at approximately four hours. That acquisition creates a new immutable manifest version rather than altering the earlier frozen set. Chinese/mixed material, a verified multi-speaker category and a verified number-dense category have not yet been established. The private manifest reports these gaps explicitly. Acquiring a four-hour source is not evidence of successful four-hour generation or quality. Synthetic tests demonstrate the known-error evaluation contract and actual preparation-artifact integration, not real long-content translation quality. The complete real comparison and replacement recommendation remain unvalidated until the required sample/provider/evaluation evidence exists.
