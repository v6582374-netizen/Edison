# YouTube 处理进度交付

已用 YouTube 内独立“处理进度”页替换原滚动浮层。阅读视图保留筛选与布局切换，重复的 YouTube 品牌标题已移除。进度页默认展示当前视频、真实阶段、后台在线状态、队列及分类异常；事件时间线按需展开。

取消处理支持逐条和本页多选。取消与自动领取通过同一 SQLite 写事务顺序协调，已经开始的条目明确返回未取消；已取消记录持续保留，刷新订阅、重启与批量失败重试均不会解除。手动恢复仍受暂停与频道排除约束，已有字幕、译文和文档不删除。

## 源码复用

直接运行从 Vegapunk 抽取的 LaunchHero、RuntimeDesk 事件呈现以及呼吸、光环、事件入场和扁平分区样式。宿主负责 YouTube 数据、阶段与后台心跳、取消/恢复契约、分页及原有操作。没有引入科研运行时或第二个服务；旧弹出面板与专属样式已删除。

固定版本、两层许可证、原始片段和适配补丁见 `../upstream/vegapunk-discovery/`。许可声明已验证进入 `surfaces/gui/dist/licenses/vegapunk-discovery.txt`，该目录是 Tauri 的前端资源输入。Vegapunk 子模块及本地克隆现已移除；已迁入的组件与来源、许可材料独立保留，运行和构建均不依赖上游仓库。

- 修改前：通过实际浏览器入口复现原浮层和重复标题，新页面回归断言失败。

- 前端：12 项阅读视图与翻译设置测试通过。
- 浏览器：5 项界面回归通过，覆盖原三种阅读视图、标题去重、异常分类、技术详情折叠、超过 50 条分页及失败继续重试。

- TypeScript / Vite 生产构建、相关 Ruff 检查、补丁空白检查通过。保留的构建提示为现有 API 混合导入与大体积 chunk 提示。
