# YouTube 处理进度页

状态：已实施并通过构建、后端与浏览器验证。本设计替代旧弹出进度面板。

## 已明确的目标

- 将当前自动更新弹出面板提升为独立页面，清晰呈现处理进程。
- 页面归属已确认：YouTube 内提供“阅读文档 / 处理进度 / 事件时间线”三个并列页面。自动更新状态只作状态展示。
- 展示深度已确认：概览优先，处理进度页展示当前任务、真实处理阶段、心跳、队列与默认展开的 raw console；事件时间线独立展示。
- 新增能力已确认：用户可以选择取消正在排队或尚未开始处理的视频；不扩大为中断正在执行的任务。
- 取消持续性已确认：取消后持续生效，自动检查订阅不会重新入队，保留记录并允许用户手动恢复。
- 删除资料库页内重复的 YouTube 图标与品牌标题；侧边栏已承担模块身份展示。
- 实际复用已抽取的 Vegapunk Discovery 运行界面与动效源码，接入 Edison 现有任务，不引入独立应用运行要求。

## 其余执行规则

本次增加选择性取消与恢复，其余限流重试、无字幕处理、暂停与恢复规则保留现状。

## 选择性取消与恢复

支持逐条取消与勾选批量取消。取消不删除已有字幕、译文或稿件，也不排除视频所属频道。若用户点击时某项已开始处理，应明确告知该项未取消；其余仍在排队的选中项正常取消。

已取消条目退出待处理数量和自动领取范围，重启应用、检查订阅及批量重试失败项均不得解除取消。处理进度页提供“已取消”筛选与手动恢复入口；恢复后重新排队，并继续遵守全局暂停和频道排除规则，不保证立即开始。取消不计为失败或成功。

## 观测边界

原 activity.snapshot 仅提供准备状态计数、批次数量、模型就绪状态、订阅发现错误及最近十条异常。本次补充当前任务、阶段更新时间、已观察阶段、最近 60 条持久化事件、后台心跳与执行线程存活状态；activity.list 分页提供完整待处理、已取消及异常列表。累计文档数与本轮已处理尝试数分别展示。

Vegapunk 的呼吸光点是视觉动画，不构成后台存活证明。迁入时必须区分执行器心跳、任务进展和界面连接状态；长时间没有新进展不直接等于执行器死亡。未知状态不得呈现为健康状态。

限流、无字幕与处理中断分别解释；技术错误保留在展开详情中。既有自动重试策略不变。

## Raw console

控制台按实际发生顺序显示任务阶段、模型请求开始、响应耗时与字符数、重试、缓存复用和检查点保存。日志与阶段时间线分别存储；控制台持久保留最近 500 条，随现有 activity.snapshot 每 4 秒更新，不增加第二条轮询通道。单条记录最多 4000 字符，删除资料时一并删除其记录。

控制台默认跟随输出，上滚阅读时停止跟随，可主动恢复。显示距最后一条输出的时间；断线时保留旧记录并说明重连状态。当前模型调用为非流式，请求等待期间不会生成虚假的输出或 token 进度，也不采集提示词、完整响应正文或凭证。

## 验证计划

实施前从 Edison 用户入口复现当前长失败列表与重复标题；实施后覆盖进入/离开进度页、持续处理、暂停/恢复、失败操作、断连与恢复、空闲、窄窗口及减少动态效果偏好。真实执行观测与使用测试替身的界面检查分别报告。

取消操作覆盖单项与批量、提交时任务已开始的竞争情况、重启与订阅刷新后仍保持取消、失败批量重试不恢复已取消项、手动恢复，以及已有资料保留。
