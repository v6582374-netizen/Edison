# Edison 作为 Minimalism 融合后的唯一产品入口

**Status: superseded by [ADR 0015](0015-remove-focus-park-items-locally.md).** items is no longer shipped.

**Status: accepted.**

融合后，Edison 是日常使用的唯一产品入口。原 Minimalism 项目保留为迁移来源，不再要求两套应用持续同步演进。相比维持两个独立产品，这一选择避免长期承担重复的功能演进与兼容成本。

这项决策仅确定产品归属，不授权删除原应用或原数据。模块的界面形态、功能范围、数据及设置迁移方式另见已确认的 融合方案（现保留于本地 items 档案）。
