# Preserve upstream translation before manuscript composition

The owner confirmed that Edison must call the complete, unchanged translation-agent workflow through its public translation entry point, preserving upstream prompts, segmentation, initial translation, reflection, revision and concatenation; optimization belongs to Edison's handling of the result. Edison must durably retain the returned complete translation unchanged and make it independently readable before manuscript composition, so a failure in that work cannot withhold an already completed translation. This strengthens the independent-preservation requirement of [ADR 0005](./0005-preserve-translation-before-manuscript-composition.md); it is an accepted design decision, not a claim that the current implementation already satisfies it.

First-release reading delivery uses copy and download, without an embedded document reader. The heading-location metadata approach considered during the discussion was set aside by the owner in favor of investigating whole-translation model composition: provide the complete retained translation and a dedicated composition prompt, requesting a complete separate reading manuscript in one response. This is the preferred direction to validate, not an established claim of sufficient single-response output capacity. It does not certify the upstream translation's semantic accuracy.

The owner approved topic headings, a table of contents, paragraphing, punctuation adjustments, removal of purely verbal fillers, and light editing of spoken sentence structure in the derived manuscript. The prompt may request preservation of meaning, tone, stance, uncertainty, viewpoints, examples, numbers, qualifications, speaker attribution and argument order, and must not request a summary. These permissions apply only to the separate manuscript and never authorize changing the retained complete translation. If composition fails because of a transient error, Edison retries it within a bound; if it still fails or the response is explicitly incomplete, Edison retains the complete translation for copy/download and reports that the reading manuscript is unavailable. A later retry runs composition only; Edison does not silently fall back to split composition or summary generation.

The owner explicitly removed complete-translation versus reading-manuscript content comparison from the acceptance process. Runtime publication therefore checks only operational response validity: non-empty output, valid saved artifact and any explicit provider truncation or incomplete-finish signal. It does not use length ratios, numeric comparison, source coverage or semantic judging to accept or reject the reading manuscript. This reduces editorial blocking at the cost of leaving semantic drift in the separate manuscript unmeasured.

Missing finish metadata alone does not block publication when the response is non-empty and saveable; an explicit provider truncation or incomplete-finish signal does. Whole-translation composition uses the same Edison-configured model and credential boundary as the rest of the task, with a separate composition prompt rather than a second model configuration.

The composition request contains only the retained complete translation and the composition instructions. It does not include the raw captions, a second translation, or independently split chapter excerpts. The model returns Markdown directly; Edison does not add a JSON/source-ID contract. A composition attempt may be retried up to three total attempts for transient transport errors or explicit truncation. Empty or unsaveable responses fail without consuming the retained translation, and a later retry runs composition only.

Composition instructions are fixed, tested and versioned by Edison rather than accepted as free-form per-task input. Each retry is bound to the same retained translation version and composition-rule version; a changed translation or changed rule produces a new reading-manuscript version. Retrying composition never regenerates the translation or overwrites an earlier successful manuscript.
